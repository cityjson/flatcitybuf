15. **The int64-policy test proves only JSON serializability.** Both calls may emit the same lossy number and pass ([plan:1357](/Users/hbbaba/tudelft/cityjson/flatcitybuf/docs/superpowers/plans/2026-07-21-native-ts-reader.md:1357)); the fixture contains only `-42` and `42` ([inferable_types.expected.jsonl:2](/Users/hbbaba/tudelft/cityjson/flatcitybuf/src/cpp/tests/conformance/inferable_types.expected.jsonl:2)). There is no unsafe integer and no assertion for decimal strings or the `'error'` policy.

16. **Most R-tree assertions are tautological.** The “single known feature” test queries the whole dataset extent and merely checks that the first full-scan ID is present ([plan:1572](/Users/hbbaba/tudelft/cityjson/flatcitybuf/docs/superpowers/plans/2026-07-21-native-ts-reader.md:1572)). Point testing compares point search with bbox search, so both can be identically wrong ([plan:1583](/Users/hbbaba/tudelft/cityjson/flatcitybuf/docs/superpowers/plans/2026-07-21-native-ts-reader.md:1583)). There is no non-default-node-size fixture, so hard-coded 16—explicitly identified as an upstream defect—passes the suite.

17. **R-tree/nearest request-count tests measure an already-warm cache.** Construction with the default 1 MB `BufferedRangeReader` reads all of `small.fcb`; clearing `inner.reads` does not clear the buffer ([plan:1621](/Users/hbbaba/tudelft/cityjson/flatcitybuf/docs/superpowers/plans/2026-07-21-native-ts-reader.md:1621), [plan:2105](/Users/hbbaba/tudelft/cityjson/flatcitybuf/docs/superpowers/plans/2026-07-21-native-ts-reader.md:2105)). Zero subsequent reads passes regardless of traversal request planning.

18. **The key tests do not cover the promised key system.** `keyKindForColumn`, `needsPostFilter`, DateTime encode/decode/order, i8/u8/i16/u16/f32, validation, and most sentinels are untested ([plan:1663](/Users/hbbaba/tudelft/cityjson/flatcitybuf/docs/superpowers/plans/2026-07-21-native-ts-reader.md:1663)). The alleged UTF-8 split uses two-byte `é` with a 50-byte boundary, so it does not split a sequence ([plan:1714](/Users/hbbaba/tudelft/cityjson/flatcitybuf/docs/superpowers/plans/2026-07-21-native-ts-reader.md:1714)).

19. **Task 14’s fixture cannot reproduce finding #5.** Every `duplicate_keys` feature has one CityObject and one value per field; `grp` is always `"same"` and `idx` is unique ([duplicate_keys.city.jsonl:2](/Users/hbbaba/tudelft/cityjson/flatcitybuf/src/cpp/tests/conformance/inputs/duplicate_keys.city.jsonl:2)). No feature carries both `k` and `k'`. Moreover, the Eq assertion accepts an empty result ([plan:1824](/Users/hbbaba/tudelft/cityjson/flatcitybuf/docs/superpowers/plans/2026-07-21-native-ts-reader.md:1824)), and `Ge == union(Gt, Eq)` still passes the broken range-minus-exact implementation because Eq adds the wrongly deleted IDs back ([plan:1835](/Users/hbbaba/tudelft/cityjson/flatcitybuf/docs/superpowers/plans/2026-07-21-native-ts-reader.md:1835)). The streaming fallback above 256 KB is entirely untested.

## Format and interface defects

23. **Task 14’s strict-bound rule is wrong for strings.** Strict `Gt`/`Lt` bounds at the truncated leaf key discard equal-prefix candidates before full-value post-filtering ([plan:1774](/Users/hbbaba/tudelft/cityjson/flatcitybuf/docs/superpowers/plans/2026-07-21-native-ts-reader.md:1774)). C++ deliberately keeps the lower/upper bound inclusive for strings and performs a full scan for string `Ne` ([stree.cpp:371](/Users/hbbaba/tudelft/cityjson/flatcitybuf/src/cpp/src/stree.cpp:371), [stree.cpp:390](/Users/hbbaba/tudelft/cityjson/flatcitybuf/src/cpp/src/stree.cpp:390)). This is required for `AAA` versus `BBB` sharing the first 50 bytes.

24. **Two other B+tree correctness fixes are omitted.** Exact search on a maximum sentinel must clamp its child descent ([stree.cpp:213](/Users/hbbaba/tudelft/cityjson/flatcitybuf/src/cpp/src/stree.cpp:213)); range search must widen its upper scan by one node ([stree.cpp:282](/Users/hbbaba/tudelft/cityjson/flatcitybuf/src/cpp/src/stree.cpp:282), [upstream-findings.md:101](/Users/hbbaba/tudelft/cityjson/flatcitybuf/docs/upstream-findings.md:101)). Task 14 calls out only two non-reference subtleties and tests neither `Eq(max)` nor a separator-valued `Le`.

25. **Decoded fixed-string keys need a byte-preserving type.** The `decodeKey(...): unknown` interface never says what strings return ([plan:1646](/Users/hbbaba/tudelft/cityjson/flatcitybuf/docs/superpowers/plans/2026-07-21-native-ts-reader.md:1646)). A truncated key can end in invalid UTF-8; converting it to a JS string with `TextDecoder` and re-encoding changes the bytes. Rust stores and orders the full fixed byte array ([key.rs:433](/Users/hbbaba/tudelft/cityjson/flatcitybuf/src/rust/fcb_core/src/static_btree/key.rs:433), [key.rs:452](/Users/hbbaba/tudelft/cityjson/flatcitybuf/src/rust/fcb_core/src/static_btree/key.rs:452)). Return a fixed `Uint8Array`/tagged byte-key for decoded entries.

26. **Full-string post-filter ordering is unspecified.** `Gt/Lt/Ge/Le` must compare full UTF-8 bytes, not JS UTF-16 strings, for the same non-BMP reason called out for index keys. C++ compares the stored UTF-8 `std::string` values ([reader.cpp:267](/Users/hbbaba/tudelft/cityjson/flatcitybuf/src/cpp/src/reader.cpp:267)); Task 15 tests Eq only.

27. **Task 12 references `AttrCondition` before it exists.** `SelectOptions.where?: AttrCondition[]` is introduced in Task 12 ([plan:1521](/Users/hbbaba/tudelft/cityjson/flatcitybuf/docs/superpowers/plans/2026-07-21-native-ts-reader.md:1521)), but `AttrCondition` is not produced until Task 14 ([plan:1763](/Users/hbbaba/tudelft/cityjson/flatcitybuf/docs/superpowers/plans/2026-07-21-native-ts-reader.md:1763)). Task 12 will not type-check independently.

28. **`FcbReader.fromReader` is required but never declared.** Task 8’s `fromFile` implementation calls it ([plan:1206](/Users/hbbaba/tudelft/cityjson/flatcitybuf/docs/superpowers/plans/2026-07-21-native-ts-reader.md:1206)), and later tests call it directly, but Task 8’s produced interface lists only `fromBytes` and `fromBlob` ([plan:1037](/Users/hbbaba/tudelft/cityjson/flatcitybuf/docs/superpowers/plans/2026-07-21-native-ts-reader.md:1037)).

29. **`fromFile` leaks its file handle.** `FileRangeReader` has `close()`, but `fromFile` hides it behind an `FcbReader` that has no close/dispose API ([plan:936](/Users/hbbaba/tudelft/cityjson/flatcitybuf/docs/superpowers/plans/2026-07-21-native-ts-reader.md:936), [plan:1037](/Users/hbbaba/tudelft/cityjson/flatcitybuf/docs/superpowers/plans/2026-07-21-native-ts-reader.md:1037)). The handle must remain open for later queries, so it cannot be closed inside `fromFile`.

30. **Query cancellation is present only in the facade type.** `SelectOptions` has a signal, but `searchRtree`, `searchStree`, and `searchNearest` have no signal/options parameter ([plan:1519](/Users/hbbaba/tudelft/cityjson/flatcitybuf/docs/superpowers/plans/2026-07-21-native-ts-reader.md:1519), [plan:1766](/Users/hbbaba/tudelft/cityjson/flatcitybuf/docs/superpowers/plans/2026-07-21-native-ts-reader.md:1766), [plan:2037](/Users/hbbaba/tudelft/cityjson/flatcitybuf/docs/superpowers/plans/2026-07-21-native-ts-reader.md:2037)). No query-level abort or early-iterator-return test exists.

31. **`transform` is optional on the wire but mandatory in `FileInfo`.** The plan requires unconditional scale/translate tuples ([plan:820](/Users/hbbaba/tudelft/cityjson/flatcitybuf/docs/superpowers/plans/2026-07-21-native-ts-reader.md:820)); the schema does not mark `transform` required ([header.fbs:131](/Users/hbbaba/tudelft/cityjson/flatcitybuf/src/fbs/header.fbs:131)), and C++ preserves its presence separately ([header.hpp:54](/Users/hbbaba/tudelft/cityjson/flatcitybuf/src/cpp/include/fcb/header.hpp:54)). Otherwise missing transform becomes indistinguishable from a real zero transform.

32. **`Json`/`Binary` policy contradicts Task 15.** Task 14 says both query kinds are rejected ([plan:1878](/Users/hbbaba/tudelft/cityjson/flatcitybuf/docs/superpowers/plans/2026-07-21-native-ts-reader.md:1878)); Task 15 says both yield candidates that must be post-filtered ([plan:1912](/Users/hbbaba/tudelft/cityjson/flatcitybuf/docs/superpowers/plans/2026-07-21-native-ts-reader.md:1912)). Only one contract can be implemented.

33. **Browser verification is ordered after wasm deletion.** Task 18 removes the fallback, while the first real browser CI coverage is Task 19 ([plan:2153](/Users/hbbaba/tudelft/cityjson/flatcitybuf/docs/superpowers/plans/2026-07-21-native-ts-reader.md:2153), [plan:2199](/Users/hbbaba/tudelft/cityjson/flatcitybuf/docs/superpowers/plans/2026-07-21-native-ts-reader.md:2199)). Browser tests should gate retirement, especially because all earlier Blob/fetch tests run in Node.

## Drop or simplify

34. **`io/bytes.ts` has no defined responsibility.** It is listed as a created file, while every test imports `BytesRangeReader` from `io/range-reader.ts` ([plan:88](/Users/hbbaba/tudelft/cityjson/flatcitybuf/docs/superpowers/plans/2026-07-21-native-ts-reader.md:88), [plan:717](/Users/hbbaba/tudelft/cityjson/flatcitybuf/docs/superpowers/plans/2026-07-21-native-ts-reader.md:717)). Either put the class in `bytes.ts` consistently or delete that file.

35. **`i8` and `str100` are dead v1 key kinds under this plan.** No column maps to `i8`, and `str100` corresponds only to Json/Binary queries that Task 14 rejects ([plan:1646](/Users/hbbaba/tudelft/cityjson/flatcitybuf/docs/superpowers/plans/2026-07-21-native-ts-reader.md:1646), [plan:1659](/Users/hbbaba/tudelft/cityjson/flatcitybuf/docs/superpowers/plans/2026-07-21-native-ts-reader.md:1659)). Drop them unless the Json/Binary policy changes.

36. **The custom reentrant-iteration error is avoidable machinery.** Native async generators serialize overlapping `next()` calls; using one behind the count-bearing cursor removes the extra state and `ReentrantIteration` error path ([plan:269](/Users/hbbaba/tudelft/cityjson/flatcitybuf/docs/superpowers/plans/2026-07-21-native-ts-reader.md:269), [plan:1097](/Users/hbbaba/tudelft/cityjson/flatcitybuf/docs/superpowers/plans/2026-07-21-native-ts-reader.md:1097)).

37. **Task 2 includes an unsafe unconditional deletion.** `rm -rf conformance` may erase an untracked corpus or local work before the move ([plan:350](/Users/hbbaba/tudelft/cityjson/flatcitybuf/docs/superpowers/plans/2026-07-21-native-ts-reader.md:350)). Detect expected contents and move the directory aside rather than deleting it.
