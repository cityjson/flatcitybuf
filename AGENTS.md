# Agent guidance

See **[CLAUDE.md](CLAUDE.md)** — it is the single source of guidance for this
repository, and applies to any coding agent, not just Claude.

It covers the four independent reader implementations and which one is the
authoritative oracle, the `just` commands, the format conventions that silently
corrupt data when missed, and where the specification lives.

This file used to carry its own copy of those rules. The copy drifted out of
date, which is why it is now a pointer.
