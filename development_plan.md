# FlatCityBuf: Go and NodeJS Bindings Development Plan

## Executive Summary

This plan outlines the implementation of native Go and NodeJS bindings for FlatCityBuf, extending support beyond the existing WASM (browser-only), Python, and C++ bindings.

**User Decisions:**
- **Go module name**: `github.com/cityjson/flatcitybuf-go`
- **Go async pattern**: Goroutines with channels for HTTP operations
- **Scope**: Reader API first, evaluate Writer after Phase 1
- **Node.js packaging**: Single unified `@cityjson/flatcitybuf` package with conditional exports (browser vs Node.js)

**Key Decision**: The existing WASM bindings (`@cityjson/flatcitybuf`) are browser-only due to `gloo-net` dependency and cannot run in Node.js. We will add **native Node.js support** to the existing package with conditional exports.

## Phase 1: Node.js Native Bindings

### 1.1 Technology Choice: napi-rs

**Rationale:**
- Mature, production-ready solution with strong community
- Better async/await support than alternatives (neon)
- Supports multiple target platforms (Windows, macOS, Linux)
- Can use native Node.js HTTP clients instead of browser-specific gloo-net

### 1.3 Core API Surface

Expose the following types and functions via `#[napi]`:

**Reader:**
```rust
#[napi]
pub struct FcbReader {
    // Internal: FcbBuffer + HTTP client
}

#[napi]
impl FcbReader {
    #[napi(constructor)]
    pub async fn new(url: String) -> Result<Self>

    #[napi]
    pub fn cityjson(&self) -> Result<JsObject>

    #[napi]
    pub fn meta(&self) -> Result<JsObject>

    #[napi]
    pub async fn select_all(&self) -> Result<FeatureIter>

    #[napi]
    pub async fn select_spatial(&self, query: &SpatialQuery) -> Result<FeatureIter>

    #[napi]
    pub async fn select_attr_query(&self, query: &AttrQuery) -> Result<FeatureIter>
}
```

**Iterator:**
```rust
#[napi]
pub struct FeatureIter {
    // Internal: selection state
}

#[napi]
impl FeatureIter {
    #[napi]
    pub async fn next(&mut self) -> Result<Option<JsObject>>

    #[napi]
    pub fn features_count(&self) -> Option<u32>
}
```

**Query Types:**
```rust
#[napi]
pub struct SpatialQuery {
    pub query_type: String,  // "bbox", "pointIntersects", "pointNearest"
    pub min_x: Option<f64>,
    pub min_y: Option<f64>,
    pub max_x: Option<f64>,
    pub max_y: Option<f64>,
    pub x: Option<f64>,
    pub y: Option<f64>,
}

#[napi]
pub struct AttrQueryCondition {
    pub field: String,
    pub operator: String,  // "Eq", "Gt", "Ge", "Lt", "Le", "Ne"
    pub value: Unknown,
}
```

## Phase 2: Go Bindings

### 2.1 Technology Choice: CGO + C Static Library

**Rationale:**
- Go has no native FFI to Rust
- CGO is the stable, well-documented approach
- Build Rust as C static library (`staticlib`)
- Use `cbindgen` to generate C headers
- **HTTP pattern**: Use goroutines with channels for concurrent operations

### 2.2 Directory Structure


### 2.3 Core API Surface (Go)

**Reader Interface:**
```go
package fcb

// FcbReader represents an open FCB file
type FcbReader struct {
    // Internal: C pointer
    reader unsafe.Pointer
}

// Open opens an FCB file for reading
func Open(path string) (*FcbReader, error)

// Metadata returns file metadata
func (r *FcbReader) Metadata() (*Metadata, error)

// Close closes the reader
func (r *FcbReader) Close() error

// SelectAll returns an iterator for all features
func (r *FcbReader) SelectAll() (*FeatureIter, error)

// SelectBBox returns features within bounding box
func (r *FcbReader) SelectBBox(bbox BBox) (*FeatureIter, error)
```

**Iterator:**
```go
// FeatureIter iterates over features
type FeatureIter struct {
    // Internal: C pointer
    iter unsafe.Pointer
}

// Next advances to the next feature
func (it *FeatureIter) Next() bool

// Current returns the current feature as JSON
func (it *FeatureIter) Current() (string, error)

// Close closes the iterator
func (it *FeatureIter) Close() error
```

**HTTP Support with Goroutines:**
```go
// For HTTP operations, use goroutines with channels for concurrency
type HttpFcbReader struct {
    // Internal: C pointer + async support
    reader unsafe.Pointer
    url string
}

// OpenHTTP opens a remote FCB file via HTTP
func OpenHTTP(url string) (*HttpFcbReader, error)

// SelectAllConcurrent returns results via channel (goroutine-based)
func (r *HttpFcbReader) SelectAllConcurrent() <-chan FeatureResult

// FeatureResult represents a feature read asynchronously
type FeatureResult struct {
    Feature string // JSON
    Error   error
}
```

### 2.7 Build Integration

The build process will involve:
1. Build Rust static library: `cargo build --release`
2. Generate C headers: `cbindgen --crate fcb_go --output src/go/include/fcb_core.h`
3. Build Go module: `go build ./...`

This can be automated with a Makefile or just script.
